## JUSTIFICACIÓN TÉCNICA DEL PROYECTO

- El desarrollo de un sistema se justifica técnicamente para lograr: mayor velocidad de procesamiento, exactitud, consistencia, seguridad, reducción de costos e integración operativa[cite: 5, 6].

## DEFINICIÓN DEL PRODUCTO (BASE PARA EL MVP)

- **Objetivo General (¿Para qué?):** Es la meta principal y global del sistema[cite: 5, 6]. Determina lo que se desea que el software haga a nivel central[cite: 5, 6].
- **Objetivos Específicos:** Representan los resultados cuantificables, módulos o etapas necesarias para cumplir el objetivo general[cite: 5, 6]. Son fundamentales para establecer el roadmap de desarrollo[cite: 5, 6].
- **Alcance (¿Qué abarca?):** Define el horizonte máximo de expectativas, listando las actividades, tareas y funcionalidades exactas que el sistema cumplirá[cite: 5, 6]. Establece qué se debe esperar del software, limitando el "scope creep" (crecimiento descontrolado del proyecto) y permitiendo definir el Producto Mínimo Viable (MVP)[cite: 5, 6].
- **Límites:** Definen las fronteras conceptuales y técnicas, indicando explícitamente qué aspectos, procesos o integraciones _no_ cubrirá el sistema[cite: 5, 6]. Representan restricciones de tiempo, recursos y viabilidad técnica[cite: 5, 6].
